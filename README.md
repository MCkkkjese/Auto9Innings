# Auto9Innings - MLB 9局職棒自動化輔助工具 ⚾



一款專為《MLB 9局職棒》Android 模擬器打造的高效能自動化輔助工具。採用 Python 開發，結合高速 ADB 連線、雙引擎 OCR 文字識別、優先動作攔截機制，以及視覺化 Scratch 積木式任務編排系統，提供全自動刷聯賽、日常任務自動領取與即時打擊輔助。



---



## 🌟 核心特色



- ⚡ **雙軌排程架構**：優先動作（Priority）無縫攔截突發事件（升階、彈窗），常規步驟（Standard）穩定推進比賽。

- 🧩 **視覺化積木流程（Task Flow）**：類似 Scratch 的拖曳式邏輯編排，支援條件分支（If/Else）、迴圈、等待條件與螢幕滑動。

- 🎯 **即時預覽與座標吸管**：內建畫面擷取預覽器，點選畫面任意位置一鍵將 (X, Y) 填入步驟。

- 🔄 **聯賽與任務清單聯動**：在聯賽自動刷中偵測特定事件後，自動跳轉執行任務清單或日常範本，完成後無縫切換回聯賽。

- 📱 **Telegram 遠端推播**：支援任務完成、重大事件通知及截圖推播。

- 🛡️ **防卡死守護機制（Watchdog）**：長時間無操作自動重啟腳本，避免卡畫面中斷運作。



---



## 🛠️ 功能模組



### 1. 聯賽自動刷關

- **優先動作**：依序判斷，一旦命中關鍵字立即打斷常規流程進行點擊或關閉視窗。

- **一般步驟**：依序循環執行比賽推進動作。

- **自訂識別**：支援繁中、簡中、英數識別過濾，支援「打勾 ✓」與「叉叉 ✕」符號比對。

- **豐富動作**：自訂座標、指定區塊、連續點擊、While 條件直到消失、排除字詞。



### 2. Scratch 式日常任務清單

- **完整積木庫**：

  - 👆 **點擊座標**：精準點擊指定座標與自訂延遲。

  - ⚡ **連續連點**：自訂次數與間隔，支援設定文字消失停止條件。

  - 🔍 **偵測文字點擊**：指定目標關鍵字、比對信心度與超時設定。

  - 🔀 **條件分支**：If / Else If / Else 判斷畫面文字執行不同點擊。

  - 🔁 **迴圈容器**：次數迴圈或 While 條件迴圈，支援巢狀子積木。

  - ⏳ **等待條件**：以自訂頻率輪詢直到指定條件成立。

  - 📱 **系統操作**：滑動手勢、模擬返回鍵、文字備註。

  - 📨 **Telegram 發送**：自訂推播文字與遊戲當前截圖。

- **範本管理**：支援獨立儲存目錄 `task_presets/`，一鍵新增、覆蓋與載入。



### 3. 即時打擊輔助

- 專為手動比賽與街頭全壘打賽事設計，透過低延遲畫面擷取偵測球速與落點，輔助最佳揮棒時機。

## 🚀 快速開始



### 環境需求

- Windows 10 / 11

- Python 3.8+

- Android 模擬器（推薦 雷電模擬器 LDPlayer、BlueStacks、MuMu）

- 模擬器解析度建議設定為：**1920 × 1080 (16:9)**



### 安裝依賴

```bash

git clone https://github.com/your-username/Auto9Innings.git

cd Auto9Innings/遊戲自動腳本

pip install -r requirements.txt

```



### 啟動程式

```bash

python main.py

```

## ⚙️ 使用指南



1. **連線模擬器**：

   - 啟動模擬器後，於上方裝置列點擊「搜尋」，選取裝置後點擊「連線」。



2. **聯賽自動刷**：

   - 切換至「聯賽自動刷」頁籤，可點擊「預設範本」載入預設打關流程。

   - 點擊「＋ 優先動作」或「＋ 一般步驟」新增自訂步驟。

   - 點擊「▶ 開始」啟動自動刷關。



3. **任務清單**：

   - 切換至「任務清單」頁籤，由左側積木庫點擊積木加入工作區。

   - 透過右側「截圖與座標選取」點擊畫面，一鍵填入座標。

   - 點擊「存檔」將常用任務保存至 `task_presets/` 供日後調用。
