# 圖像辨識遊戲運行腳本

這是一個用圖像辨識自動操作遊戲的工具。程式會截取遊戲畫面，用圖片模板比對或本機 OCR 找到按鈕與文字，然後自動點擊。

- 不修改遊戲檔案，也不讀取遊戲記憶體，只看畫面、只做點擊。
- 文字辨識在本機執行，不需要連網。
- 不限定特定遊戲，步驟可以依任何遊戲自行設定，也可以存成範本重複使用。

目前版本請見程式標題列，或參考 [CHANGELOG.md](CHANGELOG.md)。

---

## 快速開始

需要 Python 3.10–3.13。

```bash
cd 圖像辨識遊戲運行腳本
python3 -m venv venv
source venv/bin/activate        # Windows：venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
```

| 指令 | 說明 |
| :--- | :--- |
| `python3 main.py` | 開啟圖形介面（預設） |
| `python3 main.py --cli` | 不開介面，直接用預設步驟執行模擬器腳本 |
| `python3 main.py --fast` | 極簡高速反應式腳本 |
| `python3 main.py --version` | 顯示版本號 |

## 介面頁面

| 頁面 | 操作對象 | 用途 |
| :--- | :--- | :--- |
| 模擬器腳本 | Android 模擬器（ADB） | 以「優先動作」加「循序步驟」組成腳本，依序執行 |
| 視窗鏡像腳本 | macOS 視窗（預設為 iPhone 鏡像輸出） | 和模擬器腳本相同，改用滑鼠點擊視窗 |
| 任務流程 | Android 模擬器（ADB） | 用積木拼出流程，支援條件分支與迴圈 |
| 即時反應輔助 | — | 開發中，目前停用 |

### 連線

- **模擬器**：在模擬器設定中開啟 ADB 偵錯，回到程式標題列按「搜尋」，選擇裝置後按「連線」。
- **視窗鏡像**：先開啟 iPhone 鏡像輸出（或其他要操作的視窗），在視窗鏡像頁按「鎖定視窗」。macOS 會要求開啟「螢幕錄製」與「輔助使用」權限。

### 辨識模式

| 模式 | 適合情況 |
| :--- | :--- |
| 圖片特徵比對 | 按鈕外觀固定。速度快，不需要 OCR |
| 文字辨識（RapidOCR） | 按鈕上有文字，或畫面樣式常變動。可設定關鍵字與排除關鍵字 |

每個步驟還可以指定特殊目標：「勾選方塊（打勾）」與「關閉按鈕（叉叉）」。

### 循序腳本（模擬器／視窗鏡像）

1. **優先動作**：每一輪都會先檢查。只要畫面出現目標就立即處理，適合處理彈出視窗、斷線重連或「跳過」按鈕。
2. **循序步驟**：依序等待目標出現再執行。可以設定每個步驟的逾時與逾時後的處理方式。
3. **動作種類**：
   - 點擊目標中心
   - 點擊指定座標
   - 點擊自訂區塊
   - 持續連點
   - 僅等待
   - 執行任務流程
4. **進階參數**：
   - 比對間隔與信心值
   - 閒置策略：常規等待、快速跳過、自動停止
   - 等待時連點
   - 看門狗（卡住時自動重啟）
   - Telegram 通知

把優先動作設定為「執行任務清單」，偵測到事件時就會改跑任務流程，跑完再回到循序腳本。

### 任務流程

從左側積木庫把積木加入流程。積木種類包括：

- 點擊座標、連點
- 偵測並點擊
- 條件分支、迴圈
- 等待條件、等待秒數
- 滑動、返回鍵
- 註解、Telegram 通知

流程可以存成任務檔，供其他流程或循序腳本呼叫。

### 預覽畫面

- 單擊畫面：取得座標，並填入目前展開的步驟。
- 拖曳框選：裁切成模板圖片，存進存檔資料夾。

## 存檔與範本

- **存檔資料夾**：設定檔、任務檔與模板圖片都放在這裡。可以從標題列的「存檔資料夾」查看或變更。
- **自動存檔**：每個頁面都會自動存檔，下次啟動時自動載入。舊版 Auto9Innings 的存檔可以直接讀取，程式不會覆寫舊檔。
- **內建範本**：放在 `presets/`，在步驟頁或任務頁按「範本」即可載入。

| 資料夾 | 內容 |
| :--- | :--- |
| `presets/循序腳本/` | 文字辨識通用範例，以及 MLB 9 局聯賽的循序腳本 |
| `presets/任務流程/` | MLB 9 局的任務清單、全局快刷、聯賽快刷 |
| `presets/即時輔助/` | 即時反應輔助的參數 |

要新增其他遊戲，在存檔資料夾或 `presets/` 放入自己的設定檔即可。

## Telegram 通知（選用）

1. 向 @BotFather 建立機器人，取得 Token。
2. 向 @userinfobot 取得 Chat ID。
3. 把兩者填入「進階參數設定」，按「測試發送」確認能收到訊息。

也可以用環境變數 `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID` 提供預設值。Token 等同密碼，請不要把含有 Token 的設定檔提交到公開的 git 倉庫。

## 專案結構

```text
main.py                 啟動入口
version.py              版本號與更新紀錄（唯一來源）

  mirror_bot.py           macOS 視窗鏡像截圖與點擊
  task_engine.py          任務流程引擎與積木定義
  storage.py              存檔位置、設定檔讀寫
  options.py              選項常數
  imaging.py / notify.py / textutil.py / diagnostics.py / fast_bot.py / aim_assist.py
ui/                     圖形介面
  app.py                  主視窗
  script_page.py          循序腳本頁（模擬器與視窗鏡像共用）
  step_cards.py           步驟卡片
  task_page.py            任務流程頁
  widgets.py / dialogs.py / theme.py
presets/                內建範本
tools/bump_version.py   推進版本並記錄更新內容
```

開發規則（共用模組、介面規範、測試方式）見 [CLAUDE.md](CLAUDE.md)。

## 版本更新

每次修改程式後，執行下面的指令：

```bash
python3 tools/bump_version.py "這次更新的功能一" "功能二"
# 較大的更新加 --minor；不相容的改版加 --major
```

這個指令會把版本號往前推一版，並把更新內容寫入 `version.py` 與 `CHANGELOG.md`。使用者更新後第一次開啟程式時，會自動看到這一版的更新內容。
